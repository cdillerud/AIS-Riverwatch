<analysis>**original_problem_statement:**
The user wants to build a local application named River Watch to track vessels on the upper Mississippi River. The application should connect to an AIS (Automatic Identification System) TCP feed from the Boat Beacon app.

**PRODUCT REQUIREMENTS:**
1.  **AIS/GPS Data Integration:** Connect to a TCP feed to receive and parse AIS and NMEA GPS data.
2.  **Vessel Tracking:** Display the user's vessel and other commercial vessels on a simplified river map covering all 27 Upper Mississippi locks.
3.  **Lock Timing Calculation:** Calculate the required speed for the user's vessel to reach a target lock before a competing commercial vessel, including a configurable time buffer.
4.  **Alert System:** Trigger a visual alert if the required speed exceeds the user's boat's maximum speed.
5.  **Connection Management:** Allow the user to configure and manage connection settings (IP, Port, MMSI).
6.  **Local Deployment:** Provide a  setup.
7.  **Persistent Configuration:** A Settings page for persisting vessel MMSI, name, max speed, and other UI preferences.
8.  **Mobile-Friendly UI:** The application must be responsive.
9.  **USACE Data Integration:** Fetch and display lock status and historical lockage times from the U.S. Army Corps of Engineers.
10. **Tow/Barge Estimation:** Identify commercial tows, estimate barge count, and warn about potential DOUBLE LOCK delays.
11. **Map Features:** Include a map with variable zoom and always display the user's vessel.
12. **Data Visibility:** Show all available AIS data for any vessel in a detail view and provide a raw data feed for debugging.
13. **Filtering:** Persistently filter out irrelevant MMSIs.

**User's preferred language**: English
