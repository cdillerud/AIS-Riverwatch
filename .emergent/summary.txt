<analysis>**original_problem_statement:**
The user wants to build an application named River Watch to track vessels on the upper Mississippi River using an AIS (Automatic Identification System) feed provided via TCP from the Boat Beacon app.

**PRODUCT REQUIREMENTS:**
1.  **AIS Data Integration:** Connect to a TCP feed on a user-specified IP and port (default 5353) to receive and parse AIS data.
2.  **Vessel Tracking:** Display the user's vessel and other commercial vessels on a simplified river map.
3.  **Race to the Lock Calculation:** Calculate the required speed in MPH for the user's vessel to reach a target lock before a competing commercial vessel.
4.  **Alert System:** Trigger a visual alert if the required speed exceeds the user's boat's maximum speed (e.g., 25 MPH).
5.  **River Coverage:** Initially focused on Locks 2 & 3, later expanded to cover Locks 2 through 10.
6.  **Connection Management:** Allow the user to retry a failed connection and change connection settings (IP, Port, MMSI).
7.  **Local Deployment:** Provide instructions and a  setup for running the application locally on a laptop or Raspberry Pi to connect to the local AIS feed.
8.  **Persistent Configuration:** Create a Settings page where the user can enter their vessel's MMSI, name, and max speed, and have these settings persist across sessions.
9.  **Mobile-Friendly UI:** The application must be responsive and usable on mobile devices and tablets.
10. **USACE Data Integration:** Fetch and display lock status (e.g., OPEN/CLOSED) from the U.S. Army Corps of Engineers.
11. **Tow/Barge Estimation:** Identify commercial tows, estimate the number of barges, and calculate the additional lockage time, warning the user about potential long delays (e.g., DOUBLE LOCK).
12. **Map Zoom:** Add a feature to zoom the river map into the area around a selected target lock.

**User's preferred language**: English
